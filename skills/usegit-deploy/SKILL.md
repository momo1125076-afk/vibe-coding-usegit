# UseGit 构建与部署

把指定源码版本交付到明确的目标环境，分别记录构建、上传、审核、公开发布和上线验证。

## 接收输入

读取需求与目标平台、`.usegit/artifacts/adapt.json`（无需改造时读取运行基线）、源码 commit、构建方式、交付范围、目标账号/项目/环境、既有授权与成本约束。按名称接收 `vibe-coding-usegit` 的平台路线和上下文，不依赖固定兄弟目录。

按目标读取 [分平台发布手册](references/delivery-playbooks.md)；只加载本次相关平台的条目。

## 执行

1. **明确交付级别。** 主调度默认 `local` 模式，此时不会为了走流程调用云部署；`plan` 模式只做需求与选型。仅在 `preview / release` 或用户明确要求独立构建发布时执行本技能。区分本地构建、团队预览、测试分发、公开生产发布和商店提交。用户只要本地文件时，交付真实产物即可；用户要求线上服务时，生成压缩包不能算完成。
2. **核对目标与授权。** 复用当前任务中明确的账号、环境、受众、预算和发布授权。不要重复请求已经授权的操作。若新增公开范围、收费资源、商店提交或破坏性迁移超出现有范围，先准备可审查的构建、配置和影响说明，再只确认新增操作。不要把安装某个部署 Skill 当作发布授权。
3. **检查前置条件。** 查看真实工具、平台配置和登录状态，核对构建命令、环境变量名称、服务依赖、域名、证书、签名和持久化。密钥只经受支持的凭据通道或运行环境注入；不写入源代码、产物说明、日志或前端资源。
4. **固定并构建。** 记录源码 commit、锁文件、工具链、构建命令、退出码和日志。检查产物实际存在，计算校验值；构建失败先修复构建，不继续执行发布。区分各平台构建输出，避免上传开发模式或错误目标的目录。
5. **执行匹配路线。** 优先使用已连接的平台工具或已经核实的部署 Skill。Vercel、Railway、CloudBase、服务器、应用商店等路线按项目要求选择；没有可用工具时输出准确缺项，不虚构连接或链接。
6. **保存平台回执。** 记录部署 ID、构建版本、环境、URL/预览标识、受众、有效期和平台返回的状态。不要把任务已接受、文件已上传或审核中报告成已上线。只记录去除凭据和领取密钥的安全地址。
7. **交给验证。** 将产物、平台回执、版本与预期检查交给 `usegit-verify`，由它独立检查实际交付结果。构建成功与业务可用分别给证据。

## 状态与回退

主产物 `status` 仍使用统一四种结果。另在 `release` 中记录每个目标的实际阶段：`built / uploaded / preview_available / submitted / in_review / approved / published`。仅在观察到对应回执后推进；不要推测后续状态或审核时间。

发布失败时保存错误与最后一个可用版本，判断是否可以在已有授权内回滚。代码回滚与数据库恢复分别处理；迁移不可逆时先报告影响并保留数据。后台仍在构建或审核时写 `blocked` 和下次可检查的入口，避免无界轮询。

## 输出与完成条件

写入 `.usegit/artifacts/deploy.json` 与客户可读 `deploy.md`；日志、校验值等放入 `.usegit/evidence/deploy/`。使用 `schema_version: 1`、`stage: "deploy"`、`status`、`summary`、`outputs`、`evidence`、`checks`、`blockers`、`executed_actions`。可增加 `release`、`rollback`、`configuration`。

- 每条真实证据包括唯一 ID、`kind`、`claim`、`verification: "observed"`，以及提交、环境、时间和相应路径、命令/退出码或 URL。
- `executed_actions` 只登记实际完成的 `preview-deploy / production-deploy / store-submit / paid-resource / public-publish / destructive` 操作和准确目标；构建本地文件时可为空。
- 完成用户要求的交付级别且产物与回执可核验，才标 `complete`。若用户只要求“准备商店提交包”，可在准备与检查完成后交付；若要求“上架”，审核未完成仍为 `blocked`。
- 模拟部署写 `verification: "simulated"`；计划命令写 `"not-run"`。二者都不能作为线上部署通过的证据。
- 不直接写调度状态；交回主技能校验登记。
